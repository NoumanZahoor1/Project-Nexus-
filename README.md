# 🚀 ProjectNexus — Enterprise Project Management Platform

> **A high-impact, full-featured project management workspace featuring Role-Based Access Control (RBAC), interactive Kanban boards, command palettes, and real-time productivity analytics.**

## ✨ Key Features

- 🔐 **Role-Based Access Control (RBAC)**: Customized workspace portals for **Admins**, **Managers**, and **Team Members**.
- 📋 **Interactive Kanban Boards**: Drag-and-drop task workflow management with priority badges and real-time status syncing.
- ⚡ **Global `Ctrl+K` Command Palette**: Instant keyboard-driven search modal to navigate projects, tasks, and team members.
- 📊 **Executive Dashboard Analytics**: Animated stat counters, sparklines, progress bars, and Chart.js data visualizations.
- 🎨 **Modern Design System**: Built with CSS custom properties, HSL color tokens, dark mode support, and glassmorphic micro-interactions.
- 🛡️ **Production-Resilient**: Integrated React Error Boundaries, time-aware greetings, contextual breadcrumbs, and skeleton loading placeholders.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, React Router v6, Vite
- **Icons & Visuals**: Lucide React, Chart.js, React-ChartJS-2
- **Styling**: Modern Vanilla CSS (Tokens, CSS Grid, Flexbox, Animations)
- **State & Auth**: React Context API (`AuthContext`, `ThemeContext`, `ToastContext`)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/NoumanZahoor1/Project-Nexus-.git
cd Project-Nexus-
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
